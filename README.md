# مِرآة MIRAAH

> «نحافظ على المعنى، لا على الكلمات فقط»

مِرآة منظومة ذكاء اصطناعي تتتبّع **أثر المعنى** في المحتوى الإسلامي عبر سلسلة النسخ
(الأصل العربي ← ترجمة ← ملخص ← ترجمة أخرى). تكشف أين تغيّر المعنى وفي أي حلقة دخل الخلل، وتربط كل تنبيه
بمصدر، والقرار النهائي للمراجع البشري.

⚠️ **أداة مدعومة بالذكاء الاصطناعي للمساعدة في المراجعة، ولا تُصدر فتوى.**

> **الحالة:** المرحلة 1 — المسار الكامل يعمل: المحاذاة، وبصمة المعنى، والقواعد، وتحديد الحلقة التي دخل فيها الخلل،
> والتقرير. ما بُني قبل الهاكاثون موصوف في [BASELINE.md](BASELINE.md).

## كيف تعمل

1. **التقسيم** إلى جمل بالقواعد.
2. **المحاذاة**: كل نسخة تُربط جملها بجمل حلقتها الأم (استدعاء نموذج واحد)، ثم تُركَّب المحاذاة حتى الأصل.
3. **بصمة المعنى** لكل وحدة: النسبة، والحكم، والنطاق، والشروط، والاستثناءات، واليقين، والحصر، ودعوى الإجماع، ودرجة الحديث.
   النفي والأرقام تُحسب **بالقواعد** لا بالنموذج، والاقتباسات لا تُقبل إلا إن وُجدت حرفياً في النص.
4. **القواعد**: 15 قاعدة حتمية تقارن بصمة الأم ببصمة الابن (جدول 6.3 في CLAUDE.md). قبل التنبيه بسقوط شرط أو استثناء،
   يجري تحقق موجّه قصير، ولا يُلغى التنبيه إلا باقتباس حرفي من النسخة.
5. **السلسلة**: كل حلقة تُقارن بالأصل لتحديد أول حلقة دخل فيها الخلل، وبأمها لتأكيده؛ والحلقات اللاحقة «ترث» الخلل بدل تكراره.

## الواجهة البرمجية

| المسار | الوظيفة |
|---|---|
| `POST /api/analyze` | يحلل الأصل ونسخه (حتى 4) ويعيد التقرير كاملاً. مع `?background=true` يعيد المعرّف فوراً |
| `GET /api/report/{id}` | التقرير |
| `GET /api/report/{id}/status` | مرحلة التحليل الحالية |
| `GET /api/examples` | الأمثلة الجاهزة |
| `GET /api/health` | الحالة |

التوثيق التفاعلي على `/docs`.

- الرابط الحي: _يُضاف بعد النشر_

## التشغيل محلياً

```bash
python -m venv .venv
.venv/Scripts/activate        # على Linux و macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # ثم ضع ANTHROPIC_API_KEY
uvicorn app.main:app --reload
```

بعدها افتح http://localhost:8000 للواجهة، و http://localhost:8000/docs لتوثيق الواجهة البرمجية.

**الاختبارات:**
```bash
pytest -q
```

**تجربة استدعاء النموذج** (تحتاج مفتاحاً):
```bash
python scripts/llm_smoke.py
```

## التشغيل بـ Docker

```bash
docker build -t miraah .
docker run --rm -p 8000:8000 --env-file .env miraah
```

يقرأ التطبيق المنفذ من متغير `PORT`، فيعمل على Render و Hugging Face Spaces.

## سياسة البيانات
- البيانات اصطناعية فقط، ولا محادثات حقيقية ولا بيانات شخصية.
- المفاتيح في `.env` فقط، وهو مستثنى من git.
- لا يُعدَّل النص المصدر آلياً أبداً، ولا تُختلق المصادر: ما لا يوجد في المدونة المحلية يُعلَّم «غير متحقق».
